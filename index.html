ts-box rclone

ts-box rclone is a personal, non-commercial OAuth client used only by its owner. It lets rclone on the owner's home server upload backup files and other personal files to the owner's own Google Drive.

It requests only the drive.file scope, so it can access only the files it creates. It is not offered to other users.

ts-box rclone は、所有者本人だけが使う個人用の OAuth クライアントです。自宅のサーバーの rclone から、 本人の Google Drive にバックアップなどのファイルを保存するために使います。権限は drive.file（自分で作ったファイルのみ）です。
